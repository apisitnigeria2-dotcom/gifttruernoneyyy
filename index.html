📋 รายการเบอร์ที่บันทึก

กด "รีเฟรชข้อมูล" เพื่อโหลดข้อมูลจาก Google Sheets

⚠️ สำคัญ: ต้องตั้งค่า Google Apps Script ก่อนถึงจะบันทึกข้อมูลได้!

📝 ขั้นตอนการตั้งค่า Google Sheets

  1. เปิด Google Sheets สร้าง Spreadsheet ใหม่
  2. ตั้งชื่อหัวตาราง: Timestamp, Phone ในแถวแรก (A1, B1)
  3. ไปที่ Extensions → Apps Script
  4. ลบโค้ดเดิมออก แล้ววางโค้ดนี้:
  1. กด 💾 Save
  2. กด Deploy → New deployment
  3. ⚠️ ถ้าเคย Deploy แล้ว ให้กด "Manage deployments" → ไอคอนเฟือง → "New version" → Deploy
  4. เลือก type: Web app
  5. ตั้งค่า:
    • Execute as: Me
    • Who has access: Anyone
  6. กด Deploy
  7. คัดลอก Web app URL (จะขึ้นต้นด้วย https://script.google.com/...)
  8. วาง URL ด้านล่างนี้:
💡 หมายเหตุ: หลังตั้งค่าเสร็จแล้ว ทุกครั้งที่มีคนกรอกเบอร์จะบันทึกลง Google Sheets อัตโนมัติ และคุณสามารถดูข้อมูลได้ในแท็บ "ข้อมูล"
